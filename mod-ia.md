### Solution possible
Indiquer des prompts / usages sécuritaires (au sens que ces usages ne pollue pas / moins l'apprentissage)

Par exemple, si un exercice demande à un étudiant de calculer l'impot fédéral sur le revenu:
- OK `prompt exemple` "Donne moi le détail du calcul de l'impôt fédéral pour un revenue de 50000, 100000, 200000" permet à l'étudiant de comprendre le calcul sur un exemple concret
- OKish `prompt algo francais` "Donne moi en français l'algo de calcul de l'impôt fédéral" donne une description détaillée des cas mais il reste à découper en if while for etc.
- Bof bof `prompt algo pseudocode` "Donne moi en pseudocode l'algo de calcul de l'impôt fédéral"
- KO `prompt fais le à ma place` "Donne moi le code C# pour le calcul de l'impôt fédéral"

Pousser les étudiants à une forme de fierté de faire leurs exercices sans prompts.
